## 第二章：DeepSeek 网页版（核心重点）

### 2.1 它是什么？

DeepSeek 网页版是一个**AI 对话工具**。可以理解为：你有一个 24 小时在线、知识面很广、随叫随到的朋友，你可以跟它聊天、问问题、让它帮你写东西、整理信息。

它跟搜索引擎（百度、Google）最大的区别是：**搜索引擎给你一堆链接让你自己找答案，DeepSeek 直接给你整理好的答案。**

打个比方：搜索引擎是图书馆的检索目录，DeepSeek 是一个随叫随到的图书管理员——你问什么，它直接帮你读完书再讲给你听。

**能力边界：**
- 擅长：写作、翻译、总结、头脑风暴、信息整理、代码编写、逻辑推理、数学计算、分析文件
- 不擅长：预测未来、提供实时股价/天气（除非开联网搜索）、代替专业医生/律师做决策、访问需要登录的网站

### 2.2 怎么注册和登录？

**第一步：打开网页**

在浏览器地址栏输入：`https://chat.deepseek.com/`

（也可以从官网 `https://www.deepseek.com/` 点"开始对话"进入）
![[b4eaec92-c6bf-4d3d-973a-6210f7ab865d.png]]

**第二步：注册账号**

点"开始对话"或"登录"按钮，支持以下方式：
- 手机号 + 验证码
- 微信扫码
- Apple 账号

注册完成后会自动进入对话界面。

**第三步：开始第一次对话**

在页面底部输入框，输入第一个问题，比如：
![[27efb3a4-bcf0-496f-983b-e6df0eec84b1.png]]
![[419e5a60-bd67-4364-ac74-0daaaf94bd6f.png]]
> "你好，请简单介绍一下你自己"

按 `Enter` 键发送，等几秒就能看到回复。

到这里，你已经会用 AI 了。

### 2.3 界面长什么样？

界面很简洁，分两个区域：
![[68e75dc9-bede-4fec-a349-736c9645778c.png]]

#### 左侧：历史对话记录

- 保存你所有的历史对话，每条都是独立的
- 鼠标悬停在对话上，可以重命名、删除
- 建议给重要的对话起个好记的名字，比如"毕业论文辅助""旅行规划""Python 学习"
- 左上角"+"号可以新建对话
- 可以把每条对话理解为一个"专属助理"——一个专门写文案，一个专门学编程，互不干扰

#### 右侧：对话主界面

- 你和 AI 交流的主要区域
- 底部输入框，打字后按 `Enter` 发送，`Shift + Enter` 换行
- 输入框左侧有 📎 按钮，用于上传文件（后面详细讲）
- AI 的回复支持代码块、表格、列表等格式
- 回复下方有"复制""重新生成"等按钮

### 2.4 三种模式：快速、专家、识图

![[950bfdd7-3452-43e3-b3af-693594ba81e8.png]]

在输入框上方，你可以选择三种模式。**模式决定了 AI 的底层能力和响应策略**，选好模式后再开始对话。

> **注意**：同一个对话窗口里不能直接切换模式。要换模式，得新建一个对话。

| 对比项    | 快速模式            | 专家模式           | 识图模式             |
| ------ | --------------- | -------------- | ---------------- |
| 底层模型   | V4 Flash（轻量快速）  | V4 Pro（深度推理）   | V4 多模态（视觉理解）     |
| 响应速度   | 快               | 慢，需先思考再回答      | 较快，视图片大小而定       |
| 核心能力   | 文本生成、日常问答       | 逻辑推理、复杂计算      | 图片识别、图文结合分析      |
| 支持文件上传 | 支持（各类文档和图片）     | 不支持            | 支持（各类文档和图片）      |
| 适合场景   | 聊天、写邮件、翻译、快速查信息 | 数学证明、代码调试、战略规划 | 识别照片、解读图表、提取手写文字 |

**怎么选：**
- 日常提问（写文案、查资料）直接用**快速模式**，又快又省心
- 觉得快速模式"答得浅"或"算错了"，换**专家模式**重新问
- 有图片要分析，用**识图模式**并上传文件

### 2.5 两个功能开关：深度思考、智能搜索

选好模式后，在输入框附近还有两个独立的开关，**它们是附加功能，可以在任意模式下单独开启或关闭**：

| 开关         | 作用                     | 什么时候开                     |
| ---------- | ---------------------- | ------------------------- |
| **深度思考（）** | 让 AI 先思考再回答，答案更准更深，但更慢 | 复杂问题、数学题、逻辑推理、需要严谨分析的场景   |
| **智能搜索（）** | 让 AI 实时搜索互联网，获取最新信息    | 查新闻、查最新政策、查实时数据、需要最新资料的场景 |

> **模式和开关的关系**：模式（快速/专家/识图）选的是"用哪个 AI 大脑"，开关（深度思考/联网搜索）选的是"给这个大脑加什么额外能力"。两者配合使用，不是一回事。

### 2.6 怎么上传文件？

DeepSeek 网页版支持上传文件，让 AI 帮你分析内容。

**支持的格式：**
- 文档：PDF、Word (.docx)、Excel (.xlsx)、PowerPoint (.pptx)、TXT、Markdown、CSV
- 图片：JPG、PNG、GIF、WebP
- 代码文件：Python、JavaScript、Java 等各种源代码文件

**上传步骤：**
1. 点输入框左侧的 📎 按钮
2. 选择文件（也可以直接把文件拖到输入框）
3. 等上传完成，输入你的问题

**不同模式下的文件处理能力：**
- 快速模式下，仅识别图片与文件中的文字，最多 50 个，每个 100 MB
- 识图模式下，上传文件，支持各类文档和图片，最多 50 个，每个 100 MB

**常见用法：**
- 上传 PDF 论文："帮我总结这篇论文的核心观点"
- 上传 Excel 表格："分析这份销售数据，找出趋势和异常"
- 上传 Word 文档："帮我润色这篇文章"
- 上传代码文件："帮我检查这段代码有没有 bug"
- 上传图片："这张图里写了什么？""帮我分析这张图表"

**注意：**
- 超过 50 页的长文档，建议拆分后上传，或者先让 AI 总结前半部分再总结后半部分
- 扫描版 PDF（图片格式）可能无法识别文字，建议先转为可复制文字的 PDF
- 具体限制可能随官方调整而变化，以网页端实际提示为准

### 2.7 怎么提问效果更好？

很多人用 AI 效果不好，不是 AI 不行，是提问方式不对。记住这几条：

#### 说清楚你要什么，别太笼统

| 不好的提问     | 好的提问                                                          |
| --------- | ------------------------------------------------------------- |
| "帮我写点东西"  | "我需要一封求职邮件，应聘新媒体运营岗，强调 3 年公众号运营经验"                            |
| "分析这个数据"  | "这是一家奶茶店过去三个月的销售数据（把 Excel 里的数字复制粘贴进来，或者上传文件），请分析周末和工作日的销量差异" |
| "给几个营销方案" | "请用表格列出三种情人节咖啡店促销方案，包含成本预估和预期效果"                              |

> **给数据的小技巧**：如果是表格数据，可以直接从 Excel 复制数字粘贴到对话框；如果数据量大或格式复杂，直接上传文件更方便。

#### 给背景信息

AI 不了解你的情况，你给的背景越多，回答越贴合需求。

比如要减肥计划，最好告诉它：身高体重、年龄、性别、目前运动习惯、饮食情况、有没有疾病、目标是什么。

#### 指定输出格式

告诉 AI 你想要什么格式，能省很多事：
- "用表格形式列出"
- "分步骤说明，每步不超过两句话"
- "用 200 字以内解释"
- "给我 3 个选项，分别说优缺点"

#### 不满意就继续说，别重来

AI 的第一版回答往往不是最好的。在同一个对话里继续调整就行：
- "这个方案成本太高，预算控制在 500 元以内"
- "第二段太正式了，改口语化一点"
- "太长了，精简到一半"
- "换个角度再写一版"

> AI 是你的助手，不是一次性答案机器。多轮对话、反复调整，效果才最好。

### 2.8 几个小技巧

- 输入"我能用你做什么？"，AI 会自动展示功能导览
- 全新话题建议新建对话；在上一个问题基础上继续，就在原对话里说
- 养成给对话重命名的习惯，以后找起来方便
- AI 回复的代码块右上角有"复制"按钮，一键复制
- 回答不满意可以点"重新生成"让 AI 再答一次

## 第三章：实战项目

> **核心理念：用"三阶循环法"螺旋式提升自己**
> 很多人用 AI 是"问一句答一句"，用完就忘，能力没积累。高效的用法是走完一个循环：

| 阶段       | 做什么                    | 核心提问           |
| -------- | ---------------------- | -------------- |
| **认知获取** | 让 AI 帮你建立对一个领域/任务的全景认知 | "这是什么？有哪些关键点？" |
| **任务输出** | 带着认知去完成一个具体任务，在实践中检验   | "帮我做这件事"       |
| **归纳体系** | 把收获沉淀成自己的知识框架、模板或方法论   | "帮我整理成体系"      |

> 走完一轮，你比开始时更懂一点。然后带着新认知进入下一轮——这就是**螺旋式上升**。
> 下面 5 个项目从易到难，每个都演示一遍完整循环。挑最贴近你当下需求的开始。

### 3.1 快速入门一个陌生领域
> **适合谁**：学生、想转行的人、对新事物好奇的人。
> **场景**：你完全不懂"个人理财"，想开始学。打开搜索引擎全是广告和碎片文章，越看越乱。

#### 第一阶：认知获取——先画一张地图

别一上来就问"怎么理财"，问题太大答案也空。先让 AI 帮你建立坐标系。

**用户可能会这样问**：
> "我想开始学理财，但完全不懂，从哪开始？"

这时，AI 可能会给你一个比较泛的回答。这时候你可以继续追问，把需求细化：
> "我月收入 8000，没存款没负债，完全是新手。请用大白话告诉我：
> 1. 理财最核心的几个概念是什么（不超过 5 个）
> 2. 新手最容易踩哪 3 个坑
> 3. 从入门到进阶，先学什么后学什么
> 别用专业术语，必须用的时候先解释一下。"

> 小贴士：先有框架再学细节，就像先有地图再逛城市，不会迷路。

#### 第二阶：任务输出——立刻做一件具体的事

有了全景图，别停在"懂了"的阶段，马上用它做一件小事：

> "基于刚才说的，帮我定一个'第一个月理财行动清单'。
> 我月收入 8000，房租 2000，日常开销约 3000。
> 只列这个月能立刻开始做的 5 件事，每件写清楚'做什么、怎么做、花多少时间'，按优先级排。"

> 小贴士：从"知道"到"做到"隔着一道鸿沟。AI 不能替你行动，但能把"该做什么"拆到你无法拒绝的粒度。

#### 第三阶：归纳体系——沉淀成自己的笔记

一个月后，你执行了清单，有了实际体验。回来做归纳：

> "我按你给的清单执行了一个月。实际情况：
> - 记账坚持了 20 天，后来嫌麻烦停了
> - 开通了货币基金，存了 500 块
> - 尝试做预算，但总是超支
>
> 帮我分析一下哪些做得好哪些有问题，调整第二个月计划，再整理一份'我的理财入门笔记'，包括搞懂的概念、踩过的坑、下一步计划。"

> 小贴士：把学到的东西用自己的话整理出来，才是真正学会了。不整理，经验是散的；整理了，它就成了你知识库的一部分。

第一轮：有了全景图 → 执行了一个月 → 沉淀了笔记。
第二轮可以带着这些积累进入更深的领域，比如研究基金定投、学习资产配置。每一轮都比上一轮更深，不断进步。

### 3.2 高效搞定职场/学习中的写作任务
> **适合谁**：职场人士、学生、需要写东西的人。
> **场景**：领导让你写一份总结报告，你对着空白文档发呆——不知道写什么、怎么组织、写到什么程度算好。

#### 第一阶：认知获取——先搞懂"好的标准"

多数人写东西的困境不是"不会写"，是"不知道好的长什么样"。先让 AI 帮你建立标准：
> "我要写一份互联网公司运营岗的季度工作总结，给部门总监看。
> 一份优秀的总结应该包含哪几个部分？总监最关心什么、最反感什么？给我一个通用结构框架。"

> 小贴士：写作的本质不是"表达自己"，是"**满足读者的需求**"。搞清楚读者关心什么，写起来就有方向了。

#### 第二阶：任务输出——生成初稿并迭代

有了框架，把实际素材填进去，让 AI 帮你生成初稿：
> "这是我这个季度的工作内容：
> - 负责公众号运营，发了 30 篇文章，平均阅读量从 2000 涨到 3500
> - 做了 2 次线上活动，一次拉新 500 人，一次效果不好
> - 协助产品团队做了 3 次用户调研
> - 日常还处理了很多杂事
>
> 按刚才的框架帮我写一份完整初稿，用数据说话，效果不好的那次也写成'复盘与改进'，1500 字左右。"

切记，拿到初稿后别直接用，迭代两轮，甚至更多：
- 第一轮："第三部分'下季度计划'太虚了，改成具体可执行的目标，每个要有可衡量的指标。"
- 第二轮："语气太像 AI 写的了，改得像真人在汇报，口语化一点但保持专业。"

> 怎么判断要不要迭代？如果读起来"好像哪里不对但说不上来"，那就是需要迭代了。把你模糊的感觉说出来（"太正式""太啰嗦""不够具体"），AI 就能往你要的方向改。

> 小贴士：AI 的第一版是"毛坯房"，需要你"装修"才能住。这个迭代过程本身就在提升你的判断力——判断什么好、什么不好、怎么改。

#### 第三阶：归纳体系——沉淀自己的模板

这份总结写完后，别让它就这么过去了。把它变成下次能复用的资产：
> "这份总结改到满意了。帮我做两件事：
> 1. 把它抽象成一个'运营岗季度工作总结模板'，保留结构和写作要点，去掉具体数据
> 2. 写一份'工作总结写作 checklist'，写之前、写之中、写之后分别检查什么
> 以后我写任何总结都可以直接用。"

> 小贴士：一次任务的价值不只是"完成了这件事"，更在于你有没有从中提炼出可复用的方法。模板和 checklist 就是你的"个人能力资产"——积累越多，处理同类任务越快越好。

第一轮：学会了总结的标准 → 写完了一份 → 沉淀了模板。
下次写半年总结、年度总结、项目汇报时，在这个模板基础上迭代升级。每写一次，模板就更完善一次，到后面可以直接套用，省下大量精力。

### 3.3 把一本书读透并内化成自己的知识
> **适合谁**：学生、终身学习者、想做知识管理的人。
> **场景**：你买了一本很火的书，读完感觉"说得都对"，但两周后只记得书名。或者读了很多书，但它们在脑子里各自孤立，用的时候想不起来。

#### 第一阶：认知获取——先提取全书骨架

网页版支持上传 PDF/Word 文件。把书的电子版传上去（注意版权，只用于个人学习），让它帮你做"X光扫描"：

> "这是这本书的电子版。帮我做三件事：
> 1. 用不超过 300 字概括核心观点
> 2. 列出全书章节结构，每章用一句话说明核心论点
> 3. 找出书中最重要的 5 个概念，每个用'是什么+为什么重要+怎么用'三句话解释"

> 小贴士：高手读书先看骨架——核心论点是什么、怎么论证的、哪些是重点。有了骨架再读细节，就知道每段在整本书的哪个位置，不会读着读着迷路。

#### 第二阶：任务输出——生成你的专属读书笔记

有了骨架，接下来不是"继续读"，而是**带着问题去精读重点章节**，然后让 AI 帮你把收获整理成笔记：

> "基于刚才的全书骨架，我对'元认知'和'舒适区边缘'这两个概念最感兴趣。
> 帮我：
> 1. 从书中找到关于这两个概念的所有相关段落，整理出来
> 2. 用我自己的生活经历来解释（假设：我是一个经常制定计划但坚持不下去的人）
> 3. 基于这两个概念，给我设计 3 个可以立刻开始的小行动
> 4. 整理成一篇结构化读书笔记，格式包括：核心概念、我的理解、行动清单"

> 小贴士：读书笔记不是"抄书"，是"把书里的知识和你自己的生活连起来"。没有连接的知识是死的，有连接的知识是活的——你能用它解释自己的经历、指导自己的行动。

#### 第三阶：归纳体系——建立你的知识网络

一本书的笔记做完了，别让它孤立存在。把它和你已有的知识连起来：

> "我之前还读过《原子习惯》和《刻意练习》，这三本书都和'自我提升'有关。
> 帮我：
> 1. 对比这三本书的核心观点，共同点是什么、分歧点是什么
> 2. 用文字描述这三本书的核心概念之间有什么关联（比如 A 书的 X 概念和 B 书的 Y 概念是同一个东西的不同说法）
> 3. 基于这三本书，总结一套'个人成长方法论'，不超过 10 条原则
> 4. 以后再读同类书，怎么把它融入这个知识体系？"

> 小贴士：知识的价值不在于"你知道多少"，在于"你知道的东西之间有多少连接"。孤立的知识点像散落的拼图，连起来的知识像完整的地图——后者能帮你导航。
> 
> 注意：DeepSeek 网页版目前不能直接画出图形化的知识图谱，但可以用文字描述概念之间的关联。如果你需要图形，可以让 AI 输出 Mermaid 代码或思维导图文本，再用专门的工具（如 XMind、draw.io）生成图形。

第一轮：读完了一本书 → 做了笔记 → 建了三本书的关联。
第二轮读第四本同类书时，可以直接问："这本书和我已有的知识体系有什么关系？哪些是新东西？哪些是重复的？"每读一本，体系就更完整一分，理解也愈发深刻。

### 3.4 用 AI 做一次高质量的生活决策
> **适合谁**：所有人——因为每个人每天都在做决策。
> **场景**：你想安排一次 5 天的旅行，但信息太多——去哪、住哪、吃什么、怎么交通、预算多少。翻了几十篇攻略还是乱。

> 这个项目以**旅行**为例，但方法可以迁移到任何决策场景：选保险、买电脑、换工作、选学校……把"旅行"换成你正在规划的事就行。

#### 第一阶：认知获取——先搞清楚"有哪些选项"

决策的第一步不是"选哪个"，是"知道有哪些可选"。让 AI 帮你把选项列全（需要最新信息时记得开**智能搜索**）：

> "我计划 10 月份去欧洲旅行 5 天，第一次去，两个人，预算每人 8000（含机票）。
> 帮我：
> 1. 5 天适合去哪些城市组合？列 3 种不同风格的方案（经典打卡型、小众深度型、美食购物型），每种说优缺点
> 2. 10 月份欧洲天气怎么样、带什么衣服
> 3. 去欧洲最容易踩的 5 个坑
> 4. 8000 预算够吗、大概花费分布什么样"

> 小贴士：很多人做决策的困境是"在信息不足时强行选择"。你只知道两三个选项就从里面挑——但也许最好的选项你根本不知道存在。AI 的价值是帮你"扩大选项集"。

#### 第二阶：任务输出——生成具体可执行的方案

有了选项，选定一个方向，让 AI 把方案细化到"照着做就行"的程度（这一步如果需要最新的酒店价格、景点开放时间等，也保持联网搜索开启）：

> "我选'经典打卡型'：巴黎 + 罗马，5 天。
> 帮我制定详细计划：
> 1. 按天列行程，每天包括上午去哪、中午吃什么、下午去哪、晚上吃什么、住哪
> 2. 每个景点写清楚怎么去（交通方式和大概时间）、门票多少、建议玩多久、注意事项
> 3. 列详细预算表，包括机票、住宿、交通、餐饮、门票、购物
> 4. 列需要提前准备的物品清单和需要提前预订的项目
> 注意：我们喜欢美食，不喜欢太赶的行程，每天至少留 1 小时自由活动。"

> 小贴士：从"我想去旅行"到"我知道每天几点在哪、吃什么、花多少钱"，中间隔着巨大的信息整理工作。AI 能在几分钟内帮你完成过去要花几十小时做的攻略。
>
> 但注意：AI 给的方案可能有错误（比如景点已经关闭、交通时间不准），关键信息要自己核实。AI 是"高效的助手"，不是"绝对正确的导游"。

#### 第三阶：归纳体系——复盘并形成决策框架

旅行结束后，花 20 分钟做一次复盘：

> "这次旅行结束了。实际和计划有出入：
> - 巴黎的餐厅排队比预期久，导致后面行程有点赶
> - 罗马的遗迹参观体验非常好，超出预期
> - 预算超支 15%，主要是购物花多了
> - 欧洲之星火车票没提前买，现场买贵了一些
>
> 帮我复盘哪些规划做得好、哪些有问题，总结一份'旅行规划通用 checklist'，以后任何旅行都能用。再说说基于这次经验，下次再去日本或其他国家应该怎么改进规划方法。"

> 小贴士：不做复盘的旅行只是"去过了"，做了复盘的旅行才是"学到了"。每一次决策都是学习机会——你在实践中验证了哪些方法有效、哪些是坑。把经验沉淀成通用框架，下次做类似决策就不是从零开始，而是站在上次的肩膀上。

第一轮：完成了一次旅行 → 沉淀了旅行规划 checklist。
下次规划旅行时直接用这个 checklist，并在新的旅行中继续完善它。慢慢地，你会从"每次都手忙脚乱"变成"从容规划任何旅行"。

### 3.5 用 AI 做内容创作（高阶综合）

> **适合谁**：自媒体创作者、想做副业的人、需要经常输出内容的职场人。
> **场景**：你想做一个内容账号，分享"上班族高效生活"，但不知道写什么、怎么写才能有人看。

> 这里以**小红书**为例，但方法适用于任何内容平台（公众号、知乎、B站脚本等），把平台名换掉就行。

#### 第一阶：认知获取——研究赛道和爆款逻辑

别一上来就写。先让 AI 帮你搞清楚"这个赛道的游戏规则"（开智能搜索获取最新平台趋势）：

> "我想做一个小红书账号，定位'上班族的高效生活'，目标读者 25-35 岁都市白领。
> 帮我做调研：
> 1. 这个赛道目前有哪些热门内容方向，各有什么特点
> 2. 这类内容的'爆款公式'是什么，标题、封面、正文结构分别有什么规律
> 3. 给我 5 个具体选题建议，每个说清楚为什么会火、目标读者的痛点是什么
> 4. 作为新账号，前 5 篇内容怎么规划能快速起号"

> 小贴士：创作的第一个误区是"我想写什么就写什么"。内容是给读者看的，你得先搞清楚"读者想看什么"和"平台喜欢推什么"。AI 能帮你快速做竞品分析和赛道研究——自己做要刷几百篇笔记花几周，用 AI 几分钟就能拿到一个不错的起点。当然，AI 给的是"通用规律"，你还得自己去平台上验证。

#### 第二阶：任务输出——写一篇内容并迭代

选一个选题，让 AI 帮你写初稿，然后反复打磨：

> "帮我写一篇小红书笔记，选题'上班族如何用 10 分钟准备健康午餐'。
> 标题要吸引人，包含数字和痛点。正文结构：开头痛点共鸣 → 具体方法（3 个食谱，每个不超过 5 步）→ 结尾互动引导。语气像朋友聊天，加合适的 emoji 和话题标签，500 字以内。"

写完后迭代：
- 第一轮："标题不够吸引人，改 5 个版本，分别用数字型、悬念型、痛点型、对比型、反常识型。"
- 第二轮："食谱太普通了，加一个'省时小技巧'，让人觉得'哇，这个我怎么没想到'。"
- 第三轮："整体读起来还是有点像 AI 写的，加一点个人化细节，比如'我自己试了一个月，瘦了 3 斤'这种真实感。"

> 小贴士：好内容是改出来的，不是写出来的。AI 的第一版是"60 分的基础"，你的每一次迭代都在往上加分。这个过程中你在训练自己的"内容感"——什么标题好、什么节奏对、什么细节能打动人。这种感觉练出来了，你就不再依赖 AI 也能写出好内容。

#### 第三阶：归纳体系——建立你的创作流程

写了几篇之后，把经验沉淀成可复用的流程：
> "我已经写了 5 篇小红书笔记，其中 2 篇数据不错（点赞 500+），3 篇一般（点赞不到 50）。
> 帮我：
> 1. 对比数据好的和差的，分析差异在哪（标题、选题、结构、发布时间等维度）
> 2. 总结一套'我的小红书创作流程'（SOP，即标准作业流程——就是把每次都要做的步骤固定下来，不用每次都重新想），从选题到发布每步做什么、检查什么
> 3. 建一个'选题库模板'，以后有想法直接往里填
> 4. 基于前 5 篇表现，给接下来 10 篇的内容规划建议"

> 小贴士：偶尔写出一篇爆款靠运气，持续写出好内容靠体系。把"偶尔的成功"变成"可复制的成功"，你就不再需要每次都"从零开始想"，而是按流程走，质量有保障、效率也更高。这就是从业余到专业的跨越。

第一轮：研究了赛道 → 写了 5 篇 → 建立了创作流程。
第二轮用这个流程批量产出内容，同时在实践中不断优化。慢慢地，你会形成自己的内容风格和品牌，从"追热点"变成"造热点"。

### 3.6 写在最后：三阶循环法怎么迁移到其他领域？

这 5 个项目只是示例。三阶循环法适用任何领域。

**简单的，以"学编程"为例，再完整走一遍三阶：**
- **认知获取**：先让 AI 帮你画一张"编程入门地图"——学哪门语言、核心概念有哪些、学习路径是什么、新手最容易踩什么坑。不要一上来就闷头写代码，先搞清楚全貌。
- **任务输出**：选一个小项目（比如"做一个待办事项清单"），让 AI 带你一步步做。遇到报错直接把错误信息贴给 AI，让它帮你解释和修复。做完一个项目，比看 10 小时教程管用。
- **归纳体系**：做完项目后，让 AI 帮你整理"我学到了哪些核心概念""遇到了哪些错误及解决方法""下次做类似项目可以复用哪些代码模板"。把这些沉淀成自己的笔记和代码片段库。

其他领域也是同样的套路：
- **学做饭**：认知获取（了解菜系特点和基本功）→ 任务输出（做几道菜）→ 归纳体系（建立自己的食谱库）
- **找工作**：认知获取（了解行业和岗位要求）→ 任务输出（投简历、面试）→ 归纳体系（复盘面试，优化简历和话术）
- **健身**：认知获取（了解训练原理和营养知识）→ 任务输出（执行训练计划）→ 归纳体系（记录数据，调整计划）

**记住这个公式：**
> 每学一个新东西，都问自己三个问题：
> 1. 我搞懂它的全貌了吗？（认知获取）
> 2. 我用它做了一件具体的事吗？（任务输出）
> 3. 我把它沉淀成自己的东西了吗？（归纳体系）
>
> 三个都答"是"，你才真正学会了。然后进入下一轮，螺旋上升。

AI 是这个循环里的"加速器"——帮你更快获取认知、更高效产出任务、更系统归纳体系。但**走循环的人是你自己**，AI 不能替你思考、替你行动、替你沉淀。用得越多，你越强。

### 4.1 API 是什么？

**API** 是"应用程序编程接口"的缩写。说人话：**它是一座桥，让你的软件可以自动调用 DeepSeek 的 AI 能力，不需要人手动打字聊天。**

打个比方：
- **网页版**：你亲自去餐厅，看着菜单点菜，服务员把菜端给你
- **API**：你给餐厅装了一条"传送带"，冰箱一空就自动通过传送带给餐厅发订单，餐厅做好后自动送回来——全程不需要人干预

**什么时候需要用 API：**
- 想做自己的 AI 应用（智能客服、AI 写作工具等）
- 想把 AI 能力接入现有的软件/网站/小程序
- 需要批量处理大量文本（比如一次性分析 1000 条评论）
- 想让 AI 和其他工具自动配合工作（比如收到邮件自动总结、自动回复）

**什么时候不需要：**
- 只是想和 AI 聊天、问问题、写东西 → 用网页版
- 不会编程 → 网页版 + 各种现成的 AI 工具就够了

4. API 调用费用从余额中实时扣除

**扣费规则：**
- 费用 = Token 消耗量 × 模型单价
- 优先扣除赠送余额，再扣除充值余额
- 余额不足时 API 调用会失败，需要及时充值
- 可以在"用量信息"页面设置余额预警，低于某个值时自动提醒

### 4.3 怎么获取 API Key？

API Key 是你调用 API 的"钥匙"，相当于密码。有了它，你的程序才能证明"我是授权用户"。
![[811ace11-9fbd-49dd-b8a9-0371287b69f4.png]]

**获取步骤：**
1. 登录 API 开放平台
2. 点左侧"API keys"
3. 点"创建 API key"按钮
4. 给 key 起个名字（比如"我的第一个项目"），方便管理
5. 创建成功后**立刻复制保存**（它只显示一次，关掉就看不到了）
6. 妥善保管，不要泄露给别人，也不要写在公开的代码里

**"创建 API key"** ![[6ba7db6b-fbe5-4ca1-81a2-029287d0e335.png]] **复制保存 API** ![[8aebd900-2257-4522-b276-6d5b64381f68.png]] **成功创建 API** ![[a77602fa-e59f-4d4b-8d9c-04e207595ee5.png]]

**安全提醒：**
- API Key 相当于银行卡密码，谁拿到谁就能用你的余额
- 不要把 API Key 写在前端代码里（比如网页的 JavaScript），那样任何人都能看到
- 建议不同项目用不同的 API Key，方便管理和排查
- 怀疑 key 泄露了，立刻在平台上删除它，再创建一个新的

| **deepseek-v4-flash** | 速度快，价格便宜 | 日常对话、批量处理、对速度要求高的场景 |
| **deepseek-v4-pro** | 能力强，支持深度思考 | 复杂推理、代码生成、需要高质量输出的场景 |

**共同参数：**
- 上下文长度：**1M tokens**（约 70 万中文字，非常长）
- 最大输出长度：**384K tokens**
- 支持功能：JSON 输出、工具调用（Tool Calls）、对话前缀续写、FIM 代码补全
- 支持思考模式（可开启/关闭）

#### 价格说明（2026 年 8 月 17 日起生效）

DeepSeek API 实行**峰谷分时定价**：高峰时段价格较高，空闲时段价格为高峰的 50%。

- **高峰时段**：北京时间 9:00~12:00、14:00~18:00（工作日）
- **空闲时段**：其余所有时间
- **周末（周六、周日）全天**：按空闲时段价格计费（2026 年 8 月 23 日起）

**什么是"缓存命中"？**
如果你重复发送相同的内容（比如系统提示词、固定的上下文），DeepSeek 会缓存这些内容，再次使用时只收极低的费用。这是 DeepSeek 的一大优势，能大幅降低成本。

**Token 是什么？**
Token 是 AI 处理文本的最小单位，可以理解为"字"或"词"。大致的换算比例：
- 1 个中文字符 ≈ 0.6 个 token
- 1 个英文字符 ≈ 0.3 个 token

> 注意：这只是大致比例，实际消耗取决于具体分词器，以平台统计为准。1000 个中文字大约是 600 个 token，但实际可能有偏差。

**举个例子：** 你在空闲时段用 v4-flash 模型，输入 1000 个中文字（约 600 token），AI 输出 500 个中文字（约 300 token），费用大约是：
- 输入：600 ÷ 1,000,000 × 1.5 元 ≈ 0.0009 元
- 输出：300 ÷ 1,000,000 × 4.5 元 ≈ 0.00135 元
- 总计：约 0.002 元（不到一分钱）

可以看到，DeepSeek 的 API 非常便宜，普通使用一个月可能也就几块钱。

**并发限制：**
- v4-flash / v4-flash-vision-exp：每分钟最多 2500 次请求
- v4-pro：每分钟最多 500 次请求

普通用户完全用不到这个上限，只有高流量的应用才需要关注。

> 价格可能随官方调整而变化，以官方价格页 `https://api-docs.deepseek.com/zh-cn/quick_start/pricing/` 为准。

### 4.5 最简单的 API 调用示例

> 以下内容需要一点编程基础。完全不会编程可以跳过这一节，直接看 4.6 节"第三方工具接入"。

DeepSeek API 使用与 **OpenAI 兼容**的格式。如果你之前用过 OpenAI 的 API，只需要改一下 base_url 和 api_key 就能用 DeepSeek 了。

**基本参数：**
- base_url：`https://api.deepseek.com`
- api_key：你在平台上创建的 API Key
- model：`deepseek-v4-flash`、`deepseek-v4-pro` 或 `deepseek-v4-flash-vision-exp`

#### 方法一：用 curl 命令（最简单，不需要装任何东西）

在终端（命令行）里输入：

```bash
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的API_KEY" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [
      {"role": "system", "content": "你是一个乐于助人的助手。"},
      {"role": "user", "content": "你好，请简单介绍一下你自己"}
    ],
    "stream": false
  }'
```

把"你的API_KEY"替换成你自己的 key，运行后就能看到 AI 的回复。

#### 方法二：用 Python（最常用）

先安装 OpenAI SDK：

```bash
pip install openai
```

然后写代码。**建议把 API Key 存在环境变量里，不要直接写在代码中**：

```python
import os
from openai import OpenAI

# 从环境变量读取 API Key（推荐）
# 设置方法：
#   Windows: 在命令行执行 set DEEPSEEK_API_KEY=你的key
#   Mac/Linux: 在终端执行 export DEEPSEEK_API_KEY=你的key
api_key = os.environ.get("DEEPSEEK_API_KEY")

client = OpenAI(
    api_key=api_key,
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "system", "content": "你是一个乐于助人的助手。"},
        {"role": "user", "content": "你好，请简单介绍一下你自己"}
    ],
    stream=False
)

print(response.choices[0].message.content)
```

#### 开启深度思考模式

用 v4-pro 模型时，可以让它先思考再回答：

```python
response = client.chat.completions.create(
    model="deepseek-v4-pro",
    messages=[
        {"role": "user", "content": "鸡兔同笼，数头35个，数脚94只，鸡兔各几只？"}
    ],
    extra_body={"thinking": {"type": "enabled"}},
    reasoning_effort="high",  # 思考强度：low / medium / high
    stream=False
)
```

### 5.1 本地部署（进阶玩家可选）

**适合谁：**
- 有较强计算机基础的技术爱好者
- 对数据隐私有极高要求的人
- 想研究 AI 模型内部原理的人

> 硬件要求取决于你想部署的具体模型和量化方式，不同模型差异很大。建议参考官方 GitHub 仓库和社区教程（如 Ollama、LM Studio 等工具的文档），根据自己的硬件配置选择合适的模型。

### 6.2 常见问题

**Q：DeepSeek 网页版真的免费吗？有没有使用限制？**
A：网页版对话完全免费，目前没有明确的使用次数限制。但短时间内发送大量消息可能会被限速。正常使用完全没问题。

**Q：我的对话记录会被别人看到吗？**
A：你的对话记录只有你自己能看到。DeepSeek 可能会用对话数据来改进模型（这是行业惯例），但不会公开你的个人对话。如果有极高的隐私需求，可以考虑本地部署。

**Q：AI 回答错了怎么办？**
A：AI 会"幻觉"（编造不存在的信息），这是所有大模型的通病。对于重要信息（医疗、法律、财务等），一定要核实。可以开启"深度思考"模式提高准确率，也可以让 AI 给出信息来源。

**Q：为什么有时候 AI 回答很慢？**
A：可能是网络问题，也可能是服务器繁忙。可以切换到快速模式，或者稍后再试。也可以查看状态页确认服务是否正常。

**Q：上传文件后 AI 说"无法读取"怎么办？**
A：可能是文件格式不支持、文件太大、或者是扫描版 PDF（图片格式无法识别文字）。试试转换文件格式，或者把大文件拆分后上传。

**Q：API 和网页版用的是同一个模型吗？**
A：底层模型是一样的。网页版是官方封装好的聊天界面，API 是给开发者用的接口。
